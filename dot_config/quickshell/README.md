
# On screen display
The basic principle is to
only show what needs my attention.

Modules:
- time: when it's late (past 21:00)
- pomodoro: when <30s remaining
- cpu (todo): when usage >80%
- audio volume, brightness (todo): when changed
- workspaces: when switched
- battery:
    - charging: when >80%
    - discharging: when <20%

Levels:
- 0 hidden
- 1 info (white)
- 2 warn (yellow)
- 3 urgent (red-white flash)
